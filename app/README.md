# AnatomyAtlas 0.4 - anatomical exploration workspace

Interactive landmarks: click a bone in 3D, or search FMA9968 and press **Bony Markings**. T7 has six gross surface anchors with hover, persistent selection, category filtering, raycast occlusion, focus and saved landmark views. Its other 23 features are explicitly unmapped/non-surface; other bones do not receive guessed points. The complete 206-reference coverage is tracked separately (199 represented geometry, one bone with anchors). `npm run landmarks:audit` verifies triangles/checksums and writes a resumable manifest. [Landmark guide](../LANDMARK_SYSTEM.md), [coverage](../LANDMARK_COVERAGE_REPORT.md). Independent anatomical review is pending.

Knowledge extension: select Left humerus for long-form sourced anatomy, contextual tabs, 27 linked parts/surfaces/landmarks and native speech playback. Bilateral humerus/radius/ulna comprise six expanded partial drafts with 112 semantic feature profiles. Features without segmented geometry are explicitly identified. Normal selection preserves the camera; use Focus for framing.

Open `/#coverage` for all 1,171 modeled records, missing sections and the 199/206 adult-reference mapping audit. Eleven modeled profiles have partial medical content and 1,160 are metadata-only; none is fully populated or independently medically verified. Missing content is never replaced with another structure's article. TTS is approximate, not a verified medical recording.

Commands: `npm run knowledge:audit` writes normalized data, coverage and resumable checkpoints. `npm run knowledge:import -- path/to/import.json` validates without applying; see [population workflow](../CONTENT_POPULATION_WORKFLOW.md) before `--apply` or CSV imports. Current verification: 42 unit checks, 15 combined browser workflows, knowledge audit and production build passed. Production native speech completed with three voices; audible quality remains unverified. Details in [VERIFICATION.md](VERIFICATION.md).

Root / now opens the original image-led entrance; /#atlas opens regional system cards and /#workspace opens 3D directly. Cards select actual installed geometry. Continue study preserves the resident scene. The entrance fetches neither GLBs nor the deferred graphics bundle. The 32 local preview renders have canonical membership, image hashes and rights references in public/previews/manifest.json.

Entrance tools include a three-question identification exercise, saved views and visual sagittal clipping. Physiological animations, radiological images and a comprehensive quiz bank are absent. Generate licensed thumbnails with scripts/render-atlas-previews.mjs against Vite on 5175. Verify the compiled app using scripts/verify-production.mjs against preview on 4175. Both support PLAYWRIGHT_CHROMIUM_EXECUTABLE. See ../VISUAL_QA_REPORT.md and VERIFICATION.md for actual test results.

Run npm install when needed, then npm run dev -- --port 5175. Production: npm run build, then npm run preview -- --port 4175. Test: npm test and npm run test:e2e. The browser suite requires Chromium (PLAYWRIGHT_CHROMIUM_EXECUTABLE can select an existing installation).

The dark workspace includes a persistent source-aware information panel, top hierarchy, dominant 3D viewer, right tool rail and bottom anatomical system strip. Search English names, FMA IDs, checked Latin terminology and synonyms. Select a mesh to update the record; double-click or Focus frames it. Parent breadcrumbs select groups. Multi selection, isolate/hide/fade/others/reset and Undo affect actual geometry.

Tools retain opacity, notes and camera controls, with visual section clipping and exploded object separation. Library stores local named v2 scenes with camera/selection/visibility/opacity/notes. Settings controls quality, labels, motion, contrast, text size and rotation speed. / opens search, Escape closes a drawer, Ctrl/Cmd+Z undoes. Small screens support a collapsible information panel and horizontally scrolling system controls. All displayed rail controls open working panels; Store is a model-source catalogue, not a checkout.

Geometry: 1,169 BodyParts3D FMA entries plus 2 registered Z-Anatomy palmar-aponeurosis surfaces. 42 indexed GLB chunks are loaded progressively with abort/retry/disposal. Skeleton and muscle layers can be combined. Source licenses differ: BodyParts3D embedded CC BY-SA 2.1 Japan; selected palmar supplement CC BY-SA 4.0. Combined notices: public/models/ATTRIBUTION.txt. Per-model manifests remain under the two source directories. No proprietary reference assets or source application code are imported.

Knowledge is persistent, typed and bundled for offline/local retrieval. The checked pilot includes T11, palmar aponeurosis and both palmaris-longus records, with side-specific fascia aliases. Every stored medical fact cites a source. Most other entries expose geometry/terminology and explicit missing facts. No per-click AI medical generation. Source-checked does not mean independent clinical certification.

Important limits: BodyParts3D is polygon-reduced; supplemental alignment is approximate. T11 parts/facets and palmar transverse fibres are not separately segmented, and no fake highlighted submesh is substituted. Clinical content is limited; reviewed Latin terms are not available atlas-wide. Pronunciation, calibrated measurement, capped clinical cross-sections, articulated motion, cloud accounts and complete anatomical coverage are unavailable. Transient clipping/explode are not serialized in v2 views. Old v1 schematic records remain untouched.
