# Functional feature matrix - AnatomyAtlas v0.4

This is a bounded discovery inventory, not a claim to enumerate every reference-product feature. The public comparison retains the earlier official-documentation evidence; its behavior columns were not runtime-tested in the supplied Complete Anatomy application. AnatomyAtlas status describes the independent application in this workspace. AnatomyLearning live inspection remains incomplete because the supplied CDP endpoint was unreachable; screenshot findings and that limitation are recorded in [ANATOMYLEARNING_ANALYSIS.md](ANATOMYLEARNING_ANALYSIS.md).

| Build and automated verification | Passed with recorded run boundaries | Final 51 unit checks and production build passed. Combined 20 browser workflows passed before final opacity/binding hardening, followed by 6/6 targeted landmark workflows after it. All-42-GLB asset checks and landmark triangle/digest audit passed. | Blanket Z-Anatomy import | Blocked on per-asset rights | Upstream credits contain mixed-source/noncommercial exceptions. Only the two scoped palmar meshes are integrated; no blanket license assumption. |
| Rigged articulation, clinical scans, cloud and XR | Missing | Require separately licensed content, reviewed mapping or additional services; no feature-parity claim |
